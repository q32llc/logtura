# Open source path

The forwarder is open source, runs on your own infrastructure, and keeps working without us.

Use the public repo directly:

[github.com/logtura/logtura](https://github.com/logtura/logtura)

## Same foundation

The hosted control panel and the open-source packages share the same foundation. The service exists to make discovery, setup, config generation, and deployment convenient.

## Why the service exists

I built the control panel because I wanted to use it. Manually wiring provider tokens, selecting sources, rendering config, deploying a collector, and checking health is tedious. The hosted app is the lazy path for that work.

## Leaving the service

The forwarder architecture is intentionally boring. If you stop using the hosted control panel, the deployed forwarder can keep running in your infrastructure with the config it already has.
